# ClasesSinBarreras

ClasesSinBarreras es un sitio web diseñado para ayudar a estudiantes universitarios con discapacidad auditiva, proporcionando transcripción de audio a texto en tiempo real.

## Características

*   **Transcripción en Tiempo Real:** Captura el audio del micrófono y lo transcribe a texto directamente en el navegador.
*   **Interfaz Sencilla:** Diseño limpio y fácil de usar.
*   **Soporte de Idioma Español:** Configurado para reconocer y transcribir en español.
*   **Basado en Navegador:** No requiere instalación de software adicional, solo un navegador web moderno compatible con la Web Speech API (como Chrome, Edge, Firefox).

## ¿Cómo ejecutarlo localmente?

1.  **Clona o descarga este repositorio.**
    ```bash
    git clone https://github.com/tu-usuario/tu-repositorio.git
    cd tu-repositorio
    ```
2.  **Navega a la carpeta `frontend`.**
    ```bash
    cd frontend
    ```
3.  **Abre el archivo `index.html` en tu navegador web preferido.**
    *   Puedes hacer doble clic en el archivo `index.html` o arrastrarlo a la ventana de tu navegador.

4.  **Permite el acceso al micrófono.**
    *   Cuando la página cargue, tu navegador te pedirá permiso para acceder al micrófono. Debes permitirlo para que la transcripción funcione.

5.  **Inicia la transcripción.**
    *   Haz clic en el botón "Iniciar Transcripción".

## Tecnologías Utilizadas

*   HTML5
*   CSS3
*   JavaScript (Vanilla)
*   Web Speech API (para el reconocimiento de voz)
